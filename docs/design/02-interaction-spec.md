# AI WorkHub 页面与交互规格

V3 设计草案 · 2026-11-05。配套 review.html 为静态评审页面，不模拟数据保存、登录权限或真实审批。

V3.1 企业扩展：Kotech、Warmpaca 与上海安特瑞商贸有限公司的专属字段、审批及验收见 [三家企业业务设计](03-company-design.md)，场景布局见 [三企业页面稿](company-review.html)。共用页签和交互规则沿用本文件；Warmpaca 使用“商品与服务知识”等术语，上海安特瑞以用户更正后的主体为准，产品资料尚未核实。

## 1 全局框架

左侧六项导航，顶部固定展示当前企业、页面路径、个人语言、账号；企业名称在工单、导出确认中重复可见。常用动作使用明确动词，例如“登记咨询”“提交技术审核”“登记已发送”，避免泛称“生成”“完成”。

点击语言切换保留当前页面、选中工单、表单输入、滚动位置及草稿；UI 切换不改变回复语言。切换企业有未保存内容时弹出“保存并切换 / 放弃并切换 / 取消”；保存失败留在原企业，不把旧企业草稿存入新企业。

刷新后根据可访问的工单地址恢复页面；无权限显示无法访问并返回列表，不泄漏对象名称。页面加载、空结果、错误与无权限分开表达。所有异步提交显示处理中并防止重复点击；业务保存成功后显示版本或记录时间。

## 2 工作台

默认“我的工作”，管理者可切换经授权的汇总范围。顶部保留登记咨询入口；下方为逾期任务、今日任务、待我审核及最近处理。每条事项展示关联工单、明确动作、执行人或提交人、日期与状态，点击直接定位工单对应页签。

初次无工单：显示“登记第一条咨询”，附最少录入字段说明；无待办：显示暂无待办，仍可查看近期工单。无权限的企业级数量不在个人视图展示。统计不出现未经测量的提效百分比。

## 3 咨询列表与登记

列表字段：客户/主题、状态、业务阶段、负责人、下一任务及时间、更新时间。搜索客户、工单号、主题；筛选状态、负责人、逾期和阶段，显示条件及清除入口。默认按需处理事项优先，其次更新时间；允许切换最近更新。

登记使用独立抽屉或页面：客户名称/代称、主题、原话为必填；渠道、消息时间、负责人、优先级及客户地区为可选，负责人默认本人但可分配给有权接手的成员。客户原话与内部说明分栏。保存后进入需求页签，不直接进入回复页。

不要求录入电话等无必要个人信息。检测相似客户/主题只提示可能重复，不自动合并。取消登记时若有输入，确认放弃；登记失败保留输入。

## 4 工单工作区

标题区：工单号、主题、客户、状态、阶段、负责人、下一任务；右侧状态和分配操作。页签为“需求与原话 / 资料依据 / 回复与审核 / 跟进任务 / 时间线与结案”。桌面主内容约 2/3、证据与下一动作约 1/3，窄屏顺序堆叠。

### 需求与原话

上方原话卡片保留渠道、消息时间及原文。可追加新客户消息；纠正录入保留历史。下方按场景展示字段，每个字段含值、单位、确认状态、来源和最近修改。空值显示“待询问”，不将空值当零。

允许先保存不完整字段；提交技术方案前检查该场景必要字段。选择缺失项可创建预填任务，也可进入“澄清问题”回复模板。字段校验失败在字段旁解释原因，焦点移到首个失败字段。内部推测单独标为待核验，不用客户已确认颜色。

### 资料依据

搜索当前企业资料，结果默认只展示已发布有效版本，可显式查看待审核资料。每项显示型号、适用范围、来源、版本、审核人和时间、有效期。打开详情后选择“引用此版本”，工单形成证据列表。

待审核资料可供内部阅读，不能作为正式承诺依据；失效资料提示原因。无资料时可新建资料缺口任务并进入澄清回复，禁止显示“已匹配最佳机型”等没有依据的结论。

### 回复与审核

顶栏选择回复语言、回复场景、模板版本。生成规则草稿前预览哪些字段会被使用；未确认值不插入确定性表述。正文可编辑并手动保存版本；首版支持明确保存，后续可加入可见的自动保存提示。

旁栏列出字段快照、资料引用、承诺声明和阻断原因。选择“普通澄清”也须确认正文不含具体商务或技术承诺。销售核对后保存确认；承诺类选择对应授权审核人后提交，审核人看到正文、来源和变更差异。

审核动作是通过或退回；退回必填理由。作者可撤回待审版本，旧请求标为已撤回；不能编辑待审版本后继续使用旧审核。通过后显示版本、批准范围、审核人和时间，正式复制前再检查引用与字段有效性。

“复制核准正文”和“登记已发送”分开：复制显示已复制，不改变工单为已发送；登记发送需选择核准版本、实际渠道和时间。登记失败保留输入。更正已发送回复时新建更正版本与任务，不覆盖原记录。

### 跟进任务

字段：明确动作、执行人、到期时间和时区、任务类别、关联字段/审核/资料。新建必须有动作、执行人和时间；没有确切客户承诺时间时可以安排内部检查时间，并标“内部计划”。

完成任务需填写结果，必要时更新需求字段或另建任务；取消需理由。负责人停用、无权访问或离开企业时要求重新分配，不能把任务派给不可访问工单的人。等待客户也保留下一次检查任务。

### 时间线与结案

按时间记录消息、字段修改、引用变化、草稿、审核、发送登记、任务、状态与分配；可筛选事件类型。每条有人员、时间及对象版本，可展开差异。客户可见内容与内部备注分别标明。

结案弹窗列出未完成任务/审核、必需结果与原因；提示阻断项并给定位入口。允许取消或迁移任务时必须逐项说明。结案后主要内容只读，追加复盘和重开留历史。

## 5 产品与知识

左侧产品/型号列表，中部资料列表，详情展示正文、来源、适用产品、有效期和版本。明确区分“产品档案属性”和“资料正文”。空型号允许提交资料草稿，但发布必须符合资料类型规则。

维护入口支持新建草稿、从有效版创建修订、提交审核、退回修改、发布、撤回及版本差异。技术审核只能审核授权范围；作者与批准人为同一人时按企业关键资料政策阻断或要求另一个审核人。发布前显示引用影响：哪些待发草稿需要重核验。审核拒绝、无来源、已失效、重复版本都提供清晰状态。

资料缺口可从工单提交，指派维护人并关联原工单。修订发布后通知相关工单负责人重新核查，不自动更改其已发送回复。

## 6 业务模板

按场景及语言筛选，展示发布状态、版本和适用条件。模板详情标出占位符所引用的字段、条件段落和禁止自动补全项。提供脱敏样例预览；缺失字段在预览中可见，不能以示例参数代入正式工单。

模板发布由管理员管理；技术相关模板需技术审核。历史工单仍保留使用过的模板快照。外部 AI 指令默认去掉姓名、电话、邮箱等标识，显示将复制的内容并人工核对；不宣称脱敏能覆盖自由文本中所有敏感信息。结果由员工手动粘贴为草稿，标记“外部 AI 导入”，走相同审核路径。

## 7 复盘与统计

复盘从结案工单进入，也可在模块列表选择可访问工单。表单为：事实引用、问题类别、结论、改善建议、责任人及时间。无问题可记“无明显问题”，不强迫编造结论。改善建议可以建立任务。

统计分个人与企业授权范围，显示期间、分母、有效记录覆盖率和口径说明。耗时缺失显示未记录，不能显示 0。导出前展示企业、范围、字段、数量、原文是否包含、权限及用途；敏感数据默认不勾选，导出行为留审计。

## 8 企业管理

成员与角色：邀请、接受、角色与审批授权、数据范围、停用与移交。字段规则：场景、类型、单位、条件必填、发布版本及影响预览。模板与审批配置保留发布记录；在途工单使用旧规则时可见版本，并提供显式升级及差异。

审计：按人、对象、动作、时间查询；差异摘要可追溯原版本。会话：当前会话退出、查看其他有效会话并撤销；撤销后再次访问要求登录。演示数据重置只存在演示环境并标明企业，业务环境不提供。

## 9 异常与边界

| 情况 | 用户应看到的结果 |
|---|---|
| 网络中断/保存失败 | 保留当前输入，显示未保存，恢复后主动重试；不假报成功 |
| 会话过期 | 停止写入，提示重新登录；不把客户草稿持久写入共享浏览器；可选择在页面内重新登录后重试 |
| 两人同时编辑 | 显示冲突及双方差异，人工合并后保存新版本 |
| 企业切换/权限变化 | 清空无权上下文，拒绝旧上下文写入；不带出其他企业内容 |
| 资料发布新版本/失效 | 待发草稿醒目标记重新核查，已发送记录保留原快照 |
| 无审批人/审批人离职 | 提示管理员配置或移交，不能自动降级成自审 |
| 英文长文本或窄屏 | 控件换行、正文纵向排列，不隐藏关键状态或主动作 |

## 10 设计验收矩阵

| 编号 | 场景 | 通过条件 |
|---|---|---|
| D01 | 新建空压机咨询，只有原话 | 可保存；字段显示待询问；可建立澄清回复与任务 |
| D02 | 缺压力/气量/供电，拟作技术承诺 | 阻断正式技术方案；具体指出缺少什么并定位字段 |
| D03 | 引用有效资料、编辑草稿并提交 | 审核人看到精确正文和引用版本；通过结果可追溯 |
| D04 | 审核通过后修改正文或关键需求 | 原审核失效，新版本需要重新核验 |
| D05 | 已复制但未登记发送 | 不计为已发送或首次回复；页面提示待登记 |
| D06 | 创建跟进，设执行人和时区 | 工作台出现；超过到期时间显示逾期；完成有结果 |
| D07 | 发布新知识版/撤回旧版 | 历史不改写；待发草稿提示重核验/阻断失效引用 |
| D08 | 同账号双设备，一端切企业 | 独立会话互不影响；同一 token 多标签同步重载 |
| D09 | A 企业账号猜 B 企业对象编号 | 所有工单、知识、引用、导出及任务访问均拒绝且不泄漏内容 |
| D10 | 无导出权限或无审批授权 | 接口与界面均拒绝动作，不能改请求绕过 |
| D11 | 中文 → 英文 → 中文 | 页面、表单、空态与错误完整切换；原文和未保存输入不变 |
| D12 | 两人同时保存/重复点击发送登记 | 无静默覆盖，无重复记录，冲突可解决 |
| D13 | 未完成任务时结案 | 必须逐项处理；结案有结果，重开有原因 |
| D14 | 无人工计时数据 | 耗时显示未记录并给覆盖率，不展示虚构节省比例 |
| D15 | 退出/成员停用后使用旧 token | 业务请求被拒绝，未完成工作有移交入口 |

页面评审稿只帮助讨论布局和动作位置。上述场景必须在未来实现后独立验证，不能以页面可点击作为验收通过。
