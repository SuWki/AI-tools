# AI WorkHub 设计评审包

版本：V3.1 设计草案，2026-11-05。首个试点为 Kotech 空压机外贸，企业业务设计覆盖 Warmpaca 与上海安特瑞商贸有限公司。

本目录只包含设计交付物，不代表功能已开发、测试或上线。现有 V2 原型与方案保存在 ../reference，作为原始基线。V3 编号代表本轮设计迭代，不改变程序版本。

阅读顺序：

1. [产品与业务设计](01-product-design.md)：目标、范围、流程、权限、数据与指标。
2. [页面与交互规格](02-interaction-spec.md)：页面结构、操作、异常处理与验收场景。
3. [静态页面评审稿](review.html)：浏览器直接打开，通过页首目录查看六张页面稿。全部为虚构样例，无业务保存或接口调用。
4. [三家企业业务设计](03-company-design.md)：官网核对、企业差异、场景、字段、审批、资料与验收。最后一家已按用户更正为上海安特瑞商贸有限公司；没有官网资料，润滑油贸易为待核实的设计前提。
5. [三企业场景页面稿](company-review.html)：三家各两张关键场景页，共用工作台、权限和审计设计沿用基础评审稿。页面为静态布局。
6. [采购询价与离线部署设计](04-procurement-offline-design.md)：新增需求草案，覆盖十项报价、独立供应商填报、反向议价、履约变更、评估口径及免环境安装。已确认供应商在线、采购端联网同步且主数据本地保存，第 13 节详述门户与同步边界，尚未开发。

本轮形成的是可评审方案；试点数据、具体字段和审批责任仍需企业人员确认。当前不进入开发，不提交或发布。

交付检查：基础稿包含六张主页面和模板配置区，企业稿另含六张场景页面。两份稿均为无脚本静态布局，企业稿引用同目录 company-review.css，需保持两文件在一起。已检查本地链接和目录锚点；此前浏览器预览工具超时，目前未完成截图级视觉验收，宽窄屏效果仍待浏览器确认。
