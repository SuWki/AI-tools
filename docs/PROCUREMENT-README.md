# 采购模块本地体验版

2026-11-07，后端版本 3.2.0。新增采购询价与独立供应商填报，尚未部署公网服务，不是已上线采购系统。

## 使用方式

解压完整 Windows 体验包，双击“启动工作台.cmd”，等待打开 http://127.0.0.1:18081。包内含 Java 运行时、前端与后端，不用另装 Node、Java 或数据库。完成后双击“停止工作台.cmd”。数据在当前用户的 %LOCALAPPDATA%\AIWorkHub，不随删除程序包自动删除。

演示管理员 admin@workhub.demo，密码 demo1234；也可用 manager@compressor.demo 进入采购。普通 SALES 无采购权限。体验包会初始化演示账号及数据，不能直接用于真实业务上线，正式交付必须完成账号初始化、门户鉴权与部署审查。

进入“采购询价”，发布需求和费用科目，默认十项且都按同一口径的整单金额。每个供应商生成独立链接，链接仅生成时显示，须自行安全保管；当前支持链接，未生成二维码。

同机体验时门户地址保留本机地址，可在新窗口打开供应商表单。异地供应商不能访问 127.0.0.1，必须先部署公开 HTTPS 门户再改成实际地址。

供应商依次报价；截止后关闭轮次，计算最低整单价与分项最低参考组合。附加条件报价保留原文但不自动进入同口径最低价。生成目标报价后供应商可整单接受、拒绝或附条件回复。只有当前目标价被明确接受才能登记承接。可记录承接后退出、费用变化申请、确认依据与履约完成，并查看各供应商的原始统计分母。

## 独立在线门户同步

门户运行同一版本服务，但使用独立数据库。门户必须启用 procurement.portal-mode=true，此模式屏蔽内部登录、采购管理及其他内部 API，只开放供应商、收件同步和健康接口。门户与采购客户端各自设置同一个至少 32 字符的随机 procurement.relay-key，仅服务端保管，不给供应商。在采购端数据目录 portal.properties 配置 procurement.portal-url=https://实际门户地址 与 procurement.relay-key。门户端不设置 portal-url，只设置 portal-mode 与 relay-key，且不得以默认内部模式公开部署。

同步只上传冻结需求、费用、邀请及目标价；拉回供应商报价和回复，不上传本地内部事件与费用变化。链接中的邀请秘密放在 URL fragment，通过 X-Invitation 请求头使用；数据库存哈希。服务器需要正确提供同源前端与 HTTPS，管理接口应另外限制到受信任网络；当前代码未提供一键公网部署。

需求发布/新增邀请/新目标价后点击“发布到门户 / 同步收件”，供应商才会看到相应版本。采购端关机时门户可继续收件，开机后手动同步。当前是手动同步，不是定时后台队列。联网模式关闭轮次后须再同步，收齐门户报价后才允许正式比价。

## 当前边界与后续

- 需求创建时直接冻结发布；尚无改版重邀、细化单位阶梯计价、包含项/包组建模、分包优化。
- 供应商凭独立邀请访问，尚无手机号/证书实名核验、邀请撤销及重发界面；链接持有人可代表对应邀请提交，不能宣称实名不可抵赖。
- 采购方目前可查看已收到报价，尚未实现密封报价或双人开标；日志不是防电脑管理员篡改的独立凭证。
- 统计按供应商名称初步归集，展示已截止邀请报价、承接、退出和完结变更计数，不作自动归责或综合评分。尚无报价后主动撤回、细分退出原因与完整接受率面板。
- 当前价格组合是确定性计算，没有接入模型。币种首版固定 CNY；供应商提交表为中文，其他界面仍保留原双语功能。
- Windows 包是带运行时的 ZIP 体验包，不是签名 MSI，也未在另一台干净电脑上完成验收。支持一致性备份/恢复的完整管理界面尚未制作，不能承诺已具备生产灾备。

## 验证

新增 5 项采购测试、1 项公开门户边界测试和原有 7 项工作流测试，共 13 项通过。覆盖供应商数据隔离、费用精确计算、空值/负值拒绝、重复提交幂等、条件报价排除、接受后承接、费用申请、企业与版本权限及出站 HTTP 同步的发布范围。出站 HTTP 测试使用模拟收件服务器，不等于公网部署验收。前端 TypeScript 与 Vite 构建通过。

随包运行时来自 Eclipse Temurin 官方 API，下载后核对官方 SHA-256，保留原运行时授权文件。取得方式：https://adoptium.net/installation/archives 。

便携包验证：使用包内 Temurin 17 启动服务，无 Vite，静态页面返回 200。经 HTTP 实际提交两家报价 100+300、200+150，验证分项参考 250.00、最低整单 350.00、参考组合非可执行方案；供应商仅能读取本家一条报价。验证在当前电脑完成，未冒充另一台干净 Windows 验收。
