## 更新方式

在具备 python-docx 的 Python 环境执行 `python docs/handbook/build_docs.py`。本次使用 Codex 配套 Python；后续开发者可使用自己的受控文档构建环境。生成后必须使用 Word 或可用的文档渲染器逐页检查，不把脚本运行成功当作排版验收。不要把临时渲染 PDF 或页面 PNG 当成发布文件。

每次变更更新日期、代码基线、功能状态、指标分母和验证证据；涉及状态机、数据库或权限时同步对应业务测试。不得将密钥、数据库、原始客户资料写入文档。
